Import and financial data guidance

The dashboard displays only records imported into the reporting backend; it does not fabricate operational results. Every import must declare one currency using a three-letter ISO code. Files containing more than one currency are rejected as a whole; no currency conversion is performed. Monetary values must use plain decimal notation without currency symbols or grouping separators. CSV and .xlsx files are supported. Required fields include Month, Tenant, Tenant ID, Slot, Data Type and Currency; station identifiers are retained as missing when unavailable and surfaced by the data-quality check. Add stable Source Record ID values for reliable deduplication; when omitted, an ID derived from the exact file and row makes identical file retries idempotent. Imports are append-only and do not overwrite existing financial rows. Rejected rows and their validation reasons are retained in import history.
